# おさかなvlog

魚との暮らしや、旬のおさかな料理を動画で紹介する vlog サイトです。

## 特長

- **標準言語は日本語**（`<html lang="ja">`）
- 依存パッケージ不要の静的サイト（HTML / CSS のみ）
- レスポンシブ対応

## ファイル構成

| ファイル | 説明 |
| --- | --- |
| `index.html` | トップページ（日本語） |
| `style.css` | スタイルシート |

## 使い方

`index.html` をブラウザで開くだけで表示できます。

ローカルサーバーで確認する場合:

```sh
python3 -m http.server
```

ブラウザで <http://localhost:8000> を開いてください。
