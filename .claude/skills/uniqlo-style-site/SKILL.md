# UNIQLO スタイルのサイト制作

Apple が「引き算と余白」なら、UNIQLO は **「グリッドと反復」**。同じ形のタイルを規則正しく並べ、写真と価格だけで語らせる。装飾は1つもない代わりに、揃っていないことが即座にバレる設計。

## 使い方

1. `references/tokens.css` を読み込む。アクセントの赤（`--brand`）だけ差し替えれば別ブランドに転用できる。
2. `references/patterns.md` から「商品グリッド」「価格」「キャンペーンバナー」「カテゴリナビ」を組む。
3. 完成形は `examples/lookbook.html` で確認する。

## 守るべき5原則

1. **角丸と影をゼロにする。** `border-radius: 0`、`box-shadow: none`。区切りは 1px のヘアライン（`#e5e5e5`）か、面の色（`#f5f5f5`）だけ。これを破ると一気に「よくある EC」になる。
2. **すべてをグリッドに乗せる。** 画像の縦横比（商品は 3:4、バナーは 16:9 か 1:1）、カード幅、余白はページ内で完全に統一する。例外を1つ作った瞬間に崩れる。
3. **色は白・黒・グレー + 赤 1 色。** 赤はロゴ、セール価格、限定バッジ、主要 CTA **だけ**。カテゴリごとに色を変えない。
4. **写真が面積の 7 割。** 商品は白背景・同一ライティングで撮り、切り抜きの位置を揃える。カード内に文字を重ねない（画像の下に置く）。
5. **文字は小さく、密に、整列させる。** ラベル 11〜12px の大文字トラッキング広め、商品名 13〜14px、価格だけ太く大きい。行頭は必ず左で揃える。

## 価格表示の作法

EC の顔。ここだけは絶対に手を抜かない。

- 数字は**等幅**（`font-variant-numeric: tabular-nums;`）。桁が揃わないグリッドは安っぽく見える。
- 通常価格: `font-weight: 700`、16〜18px、黒。
- セール価格: 赤（`--brand`）。**元価格を消し込み**（`text-decoration: line-through;` + `--text-muted`）て右か下に小さく添える。
- 税表記（「税込」）は 11px の `--text-muted` で価格のすぐ後ろに。
- 「¥1,990」のように通貨記号と3桁区切りを常に付ける。`Intl.NumberFormat('ja-JP', { style: 'currency', currency: 'JPY' })` を使う。

## バッジ・ラベル

```html
<span class="badge badge--sale">限定価格</span>
<span class="badge">NEW</span>
```

長方形（角丸なし）、11px、`letter-spacing: .08em`、塗りは赤か黒のみ。1商品につき **最大2つ**。

## ナビゲーション

上部にユーティリティ行（検索・店舗・アカウント・カート、アイコン + 11px のラベル）、その下にカテゴリ行（WOMEN / MEN / KIDS / BABY のような大分類）。カテゴリはテキストのみ、hover で下線か赤のアンダーライン。モバイルでは横スクロールのチップ列にする（`overflow-x: auto; scroll-snap-type: x proximity;`）。

## キャンペーンバナー

全幅写真の上に、**白または赤の四角いテキストブロック**を重ねる。写真の上に直接文字を置かない（読めなくなる）。構成は「小さな英字ラベル → 大きな見出し → 1行の説明 → テキストリンク」。

## 日本語タイポグラフィ

```css
font-family: "Helvetica Neue", Helvetica, Arial, "Hiragino Kaku Gothic ProN",
  "Hiragino Sans", "Yu Gothic", Meiryo, sans-serif;
```

商品名など短い和文は `line-height: 1.5`、説明文は 1.7。英字ラベルは `text-transform: uppercase; letter-spacing: .08em;`。和文には `letter-spacing` をほぼ掛けない（0〜0.02em）。

## レスポンシブの刻み

| 幅 | 商品グリッド | 余白 |
| --- | --- | --- |
| 〜599px | 2 列 | 外 12px / 間 8px |
| 600〜1023px | 3 列 | 外 20px / 間 12px |
| 1024〜1439px | 4 列 | 外 24px / 間 16px |
| 1440px〜 | 5〜6 列 | 外 32px / 間 16px |

モバイルでも **1 列にしない**。UNIQLO 的な密度は 2 列から生まれる。

## アクセシビリティ

- 赤 `#ff0000` は白背景でコントラスト比 4.0:1。**価格や見出しなど太字・大きい文字にのみ使い**、小さい本文には使わない。CTA ボタンは赤地に白文字（4.0:1）なので 16px 太字以上にする。
- 商品画像の `alt` は「商品名 + 色」。装飾画像は `alt=""`。
- 色だけでセールを示さない。「限定価格」ラベルを併記する。
- hover での画像切り替えは、フォーカス時（`:focus-within`）にも同じ挙動にする。

## やってはいけないこと

- UNIQLO のロゴ・商標・カタカナロゴタイプ・商品写真を転用しない。**デザイン言語を借りるのであって、ブランドを騙るのではない。** 自分のブランド名で作る。
- グラデーション、ドロップシャドウ、角丸、斜体、装飾フォント、アイコンの多色使い。
- カードごとに異なる画像比率。1つでも違うとグリッドが死ぬ。
