# フロントエンド設計・実装

このリポジトリは **ビルド不要の静的サイト**（`index.html` + `style.css`）。
フレームワークもバンドラも入っていない。この構成を保つことが最優先で、必要が無い限り
npm 依存・ビルド手順・CSS フレームワークを持ち込まない。

## 着手前に必ずやること

1. `style.css` 冒頭の `:root` を読む。**色・角丸・幅はすべてここのカスタムプロパティ経由**で、値の直書きはしない。
2. 似たコンポーネントが既にあるか探す（例: カードを足すなら `.video-card` を見る）。無ければ作るが、あるなら合わせる。
3. HTML は `lang="ja"` の日本語。文言・`alt`・`aria-label` もすべて日本語で書く。

## デザイントークン（現行）

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#f4f9fb` | ページ背景（淡い水色） |
| `--color-surface` | `#ffffff` | カードなど前面の面 |
| `--color-primary` | `#0a7ea4` | ヘッダー、リンク、アクセント |
| `--color-text` | `#1f2d33` | 本文 |
| `--color-muted` | `#5c7079` | 補足テキスト、日付 |
| `--radius` | `10px` | 角丸 |
| `--max-width` | `960px` | コンテンツ幅（`.container`） |

新しい色が要るときは、直書きせず `:root` にトークンを足してから使う。
「海・水」を連想させる青系がサイトのトーン。むやみに色相を増やさない。

## 書き方の原則

- **レイアウトは flexbox / grid。** 既存の `.video-list` が `grid-template-columns: repeat(auto-fill, minmax(240px, 1fr))` でメディアクエリ無しに折り返している。この「内在的レスポンシブ」を踏襲すると、ブレークポイントを増やさずに済む。
- **余白は `rem`、線幅など細部は `px`。** 既存コードの刻み（`0.25 / 0.5 / 0.75 / 1 / 1.5 / 2.5 / 3rem`）から選ぶ。
- **セレクタはクラス単体で浅く保つ。** ID セレクタ、`!important`、3 階層以上のネストは使わない。
- **クラス名はセクション名 + 役割**（`.site-header`, `.video-card`, `.video-date`）。既存の命名に合わせる。BEM の `__`/`--` は今のところ使っていないので持ち込まない。
- **CSS は対応する HTML セクションの順に並べる。** 現在 `style.css` は header → hero → videos → about/contact → footer の順。新しいセクションも位置を合わせて追記する。
- **`box-sizing: border-box`** はグローバルに効いている（再宣言しない）。

## 守るべき品質ライン

新しい UI を足したら、以下を必ず満たす:

- **セマンティック HTML。** `<header> <nav> <main> <section> <footer>`、見出しは `h1 → h2 → h3` の順で飛ばさない。`<div>` でボタンやリンクを作らない。
- **キーボード操作。** 押せるものは `<a>` か `<button>`。フォーカスリングを消さない（消すなら `:focus-visible` で代替を用意する）。
- **コントラスト。** 本文は 4.5:1 以上。`--color-muted` (#5c7079) を白背景の本文サイズに使うのは可だが、それより薄い色は作らない。
- **画像には `alt`。** 装飾だけの要素は `aria-hidden="true"`（既存の `.thumbnail` がこの扱い）。
- **320px 幅で崩れないこと。** 横スクロールが出たら負け。
- **`prefers-reduced-motion` を尊重する。** アニメーションを足す場合は必ずガードする。

詳細は `references/patterns.md`（コンポーネントの実装例）と `references/checklist.md`（提出前チェック）を参照。

## 確認方法

ビルドは不要。ブラウザで `index.html` を開けば反映される。
ローカルで配信したい場合:

```bash
python3 -m http.server 8000    # http://localhost:8000
```

見た目の確認が必要なときは、レスポンシブ表示（320px / 768px / 1280px）を必ず見る。

## やらないこと

- Tailwind / Bootstrap などの CSS フレームワーク導入（明示的に頼まれた場合のみ）
- CSS-in-JS、SCSS などビルドが必要な仕組みの導入
- インラインスタイル（`style="..."`）の常用 — スタイルは `style.css` に置く
- 依頼されていないリデザイン。既存の見た目を変えるなら、変える範囲を先に伝える
