# 提出前チェックリスト

UI を変更したら、コミット前にこの順で確認する。

## マークアップ

- [ ] 見出しレベルが飛んでいない（`h1` → `h2` → `h3`）。ページの `h1` は 1 つ
- [ ] 一覧は `ul` / `ol`、押せるものは `a` / `button`（`div` + `onclick` にしていない）
- [ ] `img` に意味のある `alt`。装飾要素は `aria-hidden="true"`
- [ ] `label` と入力欄が `for` / `id` で結ばれている
- [ ] ランドマーク（`header` / `nav` / `main` / `footer`）が 1 ページに 1 つずつ
- [ ] 文言・`alt`・`aria-label` がすべて日本語

## スタイル

- [ ] 色・角丸・最大幅を直書きせず `var(--*)` を使っている
- [ ] 新しく足した色は `:root` にトークンとして定義した
- [ ] `!important` と ID セレクタを使っていない
- [ ] 余白が既存の刻み（0.25 / 0.5 / 0.75 / 1 / 1.5 / 2.5 / 3rem）に乗っている
- [ ] CSS の追記位置が HTML のセクション順と一致している
- [ ] インラインスタイルを残していない

## レスポンシブ

- [ ] 320px で横スクロールが出ない
- [ ] 768px / 1280px でレイアウトが破綻しない
- [ ] `max-width: var(--max-width)` を超えて間延びしない
- [ ] 画像に `width` / `height`（または `aspect-ratio`）があり、読み込み時にガタつかない

## アクセシビリティ

- [ ] Tab キーだけで全リンク・全ボタンに到達でき、フォーカス位置が見える
- [ ] 本文のコントラスト比 4.5:1 以上、大きい文字は 3:1 以上
- [ ] 色だけで情報を伝えていない（状態はテキストや形でも示す）
- [ ] アニメーションが `prefers-reduced-motion` を尊重している

## 最後に

- [ ] ブラウザで `index.html` を開いて実際に見た
- [ ] 既存ページの見た目を意図せず変えていない（差分を読み返す）
- [ ] `git diff` に不要な整形変更が混ざっていない
