# デザイン性の高いサイトを作る

「おしゃれにして」と言われたときにやることは、装飾を足すことではなく **1つのデザイン言語を選び、最後まで一貫させること**。このスキルは (1) 言語の選び方、(2) どのテイストでも共通の土台、(3) 出荷前チェックの3つを提供する。

## 手順

1. **言語を決める。** `references/design-languages.md` からプロジェクトに合うものを1つ選ぶ（迷ったら下の早見表）。混ぜない。
2. **トークンを固定する。** 選んだ言語の色・フォント・角丸・余白スケールを CSS 変数として最初に書き切る。以後、生の値（`#333`, `13px`, `border-radius: 6px`）をコード中に直接書かない。
3. **土台を守る。** `references/foundations.md` のタイプスケール・8px グリッド・行長・日本語組版に従う。
4. **出荷前に検査する。** `references/quality-checklist.md` を上から順に潰す。

## 早見表

| 作りたいもの | 選ぶ言語 | 参照 |
| --- | --- | --- |
| プロダクト紹介・LP・テック系 | Apple | `apple-style-site` スキル |
| EC・商品一覧・カタログ | UNIQLO | `uniqlo-style-site` スキル |
| 生活雑貨・食品・和のブランド | MUJI（無印良品） | `references/design-languages.md#muji` |
| スポーツ・エネルギー・若年層 | Nike | 同 `#nike` |
| 宿泊・予約・コミュニティ・アプリ紹介 | Airbnb | 同 `#airbnb` |
| SaaS・開発者向け・ダッシュボード | Stripe | 同 `#stripe` |
| 読み物・ポートフォリオ・写真 | Editorial（北欧・雑誌型） | 同 `#editorial` |
| 個人ブログ・vlog | MUJI か Editorial | 同 |

## どの言語でも共通する「品質の正体」

1. **揃っている。** 余白が 8 の倍数、画像比率が統一、行頭が揃っている。デザインが上手く見える理由の8割はこれ。
2. **階層が3段以内。** 見出し / 本文 / 補足。フォントサイズを5種類以上使った時点で散らかる。
3. **色数が少ない。** 無彩色 + アクセント1色が基本。2色目を足すのは、意味（成功/警告）が必要なときだけ。
4. **写真が良い。** 素材が弱いとどんな CSS でも救えない。比率を揃え、明るさ・彩度を揃え、被写体の位置を揃える。無い場合は写真を使わず、タイポグラフィと面の色だけで構成する（下手な素材写真より強い）。
5. **速い。** 画像は `width`/`height` 指定 + `loading="lazy"` + WebP/AVIF。Web フォントは最大2ウェイト、`font-display: swap`。装飾のための JS を入れない。
6. **崩れない。** 360px 幅と 1920px 幅で必ず確認する。横スクロールが出たら負け。

## よくある失敗と直し方

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| 「なんか素人っぽい」 | 余白がバラバラ | 余白を 4 段階（8/16/32/64）に固定して全部当て直す |
| 「ごちゃごちゃ」 | 色とフォントサイズが多い | アクセントを1色に、サイズを4種類に減らす |
| 「安っぽい」 | 影・グラデ・角丸の多用 | 影を全部消し、区切りを面の色か 1px 罫線に置換 |
| 「読みにくい」 | 行長が長すぎ・行間が狭い | 和文は 1 行 25〜40 字、`line-height: 1.7〜1.8` |
| 「間延びしてる」 | 余白は広いが階層がない | 見出しを大きく・太く、本文との差を 2 倍以上つける |

## ブランドを借りるときの線引き

これらは**デザインの考え方（グリッド・配色の構造・タイポグラフィの扱い方）を学んで自分のブランドに適用する**ためのプリセット。ロゴ、商標、独自書体、商品写真、キャッチコピーを転用しない。「無印良品のサイトのコピー」ではなく「静謐で余白の広い自分のブランドのサイト」を作る。実在ブランドの名前・ロゴをページに出してよいのは、そのブランド自身の仕事をしているときだけ。
