# 共通の土台（どの言語でも同じ）

## 1. 余白スケール

4px を基準に、**使ってよい値を先に決める**。中間値を作らない。

```
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128
```

- 要素の内側（padding）: 12〜32
- 関連する要素の間: 8〜16
- 意味のまとまりの間: 24〜48
- セクション間: 64〜128（`clamp()` でモバイルは 1/2 に）

```css
--section-y: clamp(48px, 8vw, 128px);
```

## 2. タイプスケール

比率 1.25（Major Third）を基準にした 5 段階。**これ以上増やさない。**

| 役割 | デスクトップ | モバイル | weight | line-height |
| --- | --- | --- | --- | --- |
| Display | 56–80px | 32–40px | 600–800 | 1.05–1.15 |
| Heading | 28–40px | 22–26px | 600–700 | 1.2–1.3 |
| Subhead | 18–24px | 16–18px | 400–500 | 1.5 |
| Body | 15–17px | 15–16px | 400 | 1.7–1.8（和文） |
| Caption | 11–13px | 11–12px | 400–600 | 1.4 |

```css
--fs-display: clamp(32px, 6vw, 72px);
--fs-heading: clamp(22px, 3.5vw, 40px);
--fs-subhead: clamp(16px, 2vw, 22px);
--fs-body: 16px;
--fs-caption: 12px;
```

**文字サイズは 14px 未満を本文に使わない**（モバイルは 16px 未満だと iOS で入力時にズームする）。

## 3. 日本語組版

- 本文 `line-height` は **1.7〜1.8**（欧文の 1.5 では詰まって見える）。
- 1 行の長さは **25〜40 字**。`max-width: 34em` 前後。
- 和文には `letter-spacing` をほぼ掛けない（0〜0.02em）。掛けるのは英字ラベルだけ（0.06〜0.16em）。
- 大きい見出しだけ `font-feature-settings: "palt" 1;` で約物を詰める。本文に掛けると読みにくい。
- 改行位置を制御したい短い見出しは `<wbr>` か `word-break: auto-phrase;`（対応ブラウザのみ）を使い、`<br>` の直書きは避ける（レスポンシブで崩れる）。
- フォント指定は「欧文 → 和文」の順に並べる。逆にすると英数字が和文フォントで描かれて野暮ったくなる。

```css
font-family: Helvetica, Arial, "Hiragino Kaku Gothic ProN", "Hiragino Sans",
  "Yu Gothic", Meiryo, sans-serif;
```

## 4. 配色の作り方

1. **無彩色を5段**決める（背景 / 面 / 罫線 / 二次文字 / 本文）。
2. **アクセントを1色**決める。使う場所は「主要 CTA・リンク・現在地」の3つだけ。
3. 意味色（成功 #0f7b3f / 警告 #a15c00 / エラー #b3261e）は必要になってから足す。
4. 影を使うなら **1種類だけ**定義して全箇所で使い回す。

コントラスト比の最低ライン: 本文 4.5:1、18px 以上の太字・UI 部品の境界 3:1。二次テキストの `#999` は白背景で 2.8:1 しかない。**`#767676` まで暗くする。**

## 5. レスポンシブのブレイクポイント

```
600px（2→3列） / 834px（タブレット・2カラム化） / 1024px（4列） / 1440px（最大幅到達）
```

- モバイルファーストで書く（`min-width` メディアクエリ）。
- 画面幅ではなく**コンテンツが破綻する幅**でブレイクさせる。「iPhone の幅」に合わせない。
- 最小 **320px** で横スクロールが出ないこと。長い英単語・URL は `overflow-wrap: anywhere;`。

## 6. 画像

```html
<img src="photo.avif" alt="説明" width="1600" height="1200" loading="lazy" decoding="async">
```

- `width`/`height` を必ず入れる（CLS 防止）。
- ファーストビューの画像だけ `loading="eager" fetchpriority="high"`。
- 比率は `aspect-ratio` + `object-fit: cover` でページ内統一。
- 装飾画像は `alt=""`。意味のある画像は「何が写っているか」を書く。

## 7. Web フォント

- 使うなら **2 ウェイトまで**（例: 400 と 700）。日本語 Web フォントは 1 ウェイトで数 MB になるので、サブセット化するか採用しない。
- `font-display: swap` + `<link rel="preconnect">`。
- 和文はシステムフォント（Hiragino / Yu Gothic / Noto Sans JP のローカル参照）で十分美しい。欧文だけ Web フォントにするのが軽くて効く。

## 8. インタラクション

- hover の変化は **色または不透明度**。`transform` を使うなら 1.02〜1.03 倍まで。
- duration は 150〜250ms（UI）、400〜800ms（スクロール出現）。
- `:focus-visible` のリングを必ず残す。
- `@media (prefers-reduced-motion: reduce)` で全アニメーションを止める。
- タップ領域は最低 44×44px。
