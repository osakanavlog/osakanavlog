# 出荷前チェックリスト

上から順に潰す。1つでも残っていたら「デザインが良い」とは言えない。

## 整列・一貫性
- [ ] 余白の値が決めたスケール（4/8/12/16/24/32/48/64/96/128）以外に存在しない
- [ ] 画像の縦横比がページ内で統一されている
- [ ] 角丸の値が 1〜2 種類に収まっている
- [ ] 影は 0 種類か 1 種類
- [ ] フォントサイズが 5 段階以内
- [ ] カード・セクションの左端が全部揃っている

## 色・コントラスト
- [ ] アクセント色は 1 色。使用箇所は CTA・リンク・現在地のみ
- [ ] 本文のコントラスト比 4.5:1 以上（二次テキストも）
- [ ] 色だけで情報を伝えていない（セール・エラー・必須にラベルがある）
- [ ] ダークモードで背景・文字・罫線が個別に定義されている（単純反転していない）

## タイポグラフィ
- [ ] 和文本文の `line-height` が 1.7 以上
- [ ] 1 行が 25〜40 字に収まっている
- [ ] 本文が 14px 以上、フォーム入力が 16px 以上
- [ ] `<br>` でレイアウトを作っていない

## レスポンシブ
- [ ] 320px / 375px / 768px / 1280px / 1920px で崩れない
- [ ] どの幅でも横スクロールが出ない
- [ ] モバイルでタップ領域が 44px 以上
- [ ] 画像に `width`/`height` があり、読み込み中にレイアウトが跳ねない

## アクセシビリティ
- [ ] 見出しが h1 → h2 → h3 の順に飛ばさず並んでいる
- [ ] すべての画像に適切な `alt`（装飾は `alt=""`）
- [ ] キーボードだけで全リンク・ボタン・フォームを操作でき、フォーカスが見える
- [ ] `prefers-reduced-motion: reduce` でアニメーションが止まる
- [ ] ナビゲーションに `aria-label`、現在地に `aria-current="page"`
- [ ] `lang="ja"` が指定されている

## パフォーマンス
- [ ] 画像が WebP/AVIF で、ファーストビュー以外は `loading="lazy"`
- [ ] Web フォントが 2 ウェイト以内、`font-display: swap`
- [ ] 装飾のためだけの JS ライブラリを読んでいない
- [ ] CSS に未使用のリセット・フレームワークが残っていない

## メタ・共有
- [ ] `<title>` と `<meta name="description">` がページごとに違う
- [ ] OGP（`og:title` / `og:description` / `og:image` 1200×630）がある
- [ ] favicon がある
- [ ] 404 とフォームの成功/失敗状態のデザインがある

## 最終確認
- [ ] 実装を見ずにスクリーンショットだけ見て、「どのデザイン言語か」が言える
- [ ] 1 画面に伝えたいことが 1 つだけになっている
