# おさかなvlog vault

このフォルダが Obsidian の vault です。Obsidian で「フォルダーを Vault として開く」から、この `vault` フォルダを選んでください。

```
vault/
├── videos/     … 動画ノート（1 本 = 1 ファイル）。ここがサイトの元データ
├── templates/  … 新規ノート用テンプレート
└── assets/     … 画像などの添付ファイル
```

## Obsidian 側のおすすめ設定

| 設定 | 場所 | 値 |
| --- | --- | --- |
| 新規ノートの保存先 | 設定 → ファイルとリンク → 新規ノートの作成場所 | `videos` |
| 添付ファイルの保存先 | 設定 → ファイルとリンク → 添付ファイルの保存場所 | `assets` |
| テンプレートの場所 | 設定 → コアプラグイン → テンプレート | `templates` |

この設定にしておくと、`Ctrl/Cmd + N` で作ったノートがそのまま公開対象になり、貼り付けた画像も自動で `assets/` に入ります。

## ノートの書きかた

ファイル名は `YYYY-MM-DD-タイトル.md` の形にします。先頭の日付は公開 URL からは自動で取り除かれます（`2026-07-01-はじめての水槽づくり.md` → `videos/はじめての水槽づくり.html`）。

先頭のフロントマターで、サイトの表示を指定します。

| キー | 説明 |
| --- | --- |
| `title` | 動画のタイトル。省略するとファイル名が使われます |
| `date` | 公開日（`YYYY-MM-DD`）。一覧はこの日付の新しい順に並びます |
| `summary` | 一覧カードの説明文。省略すると本文の最初の段落が使われます |
| `thumbnail` | サムネイル画像。`assets/` 内のファイル名か、`https://` から始まる URL |
| `youtube` | YouTube の動画 ID または URL。指定すると動画ページに埋め込まれます |
| `tags` | `[飼育, 料理]` のように書きます |
| `draft` | `true` のあいだはサイトに出力されません。公開するときに `false` へ |

本文では Obsidian の記法がそのまま使えます。

- `[[2026-06-20-旬のあじをさばく|旬のあじをさばく]]` … 他の動画ページへのリンクになります
- `![[写真.png]]` … `assets/` の画像が記事に表示されます
- 見出し・箇条書き・引用・コードブロック・太字・リンクに対応しています

## 公開の手順

1. Obsidian でノートを書く（下書きのうちは `draft: true`）
2. 公開したくなったら `draft: false` にする
3. リポジトリのルートで `npm run build` を実行する
4. 生成された `index.html` と `videos/` をコミットする

`npm run build` は `index.html` の動画一覧を書きかえ、`videos/` 以下のページを作り直し、`assets/` をサイト直下へコピーします。手で編集するのは vault のノートだけで、生成物は触らなくて構いません。
